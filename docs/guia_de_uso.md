1. Descripción 

El Analizador de Chat de WhatsApp permite cargar únicamente un archivo .txt exportado desde WhatsApp y generar métricas sobre la conversación, presentadas en un panel visual facilitando la comprensión del usuario.

2. Requisitos

Navegador web (Chrome, Firefox, Edge).
Archivo de chat exportado desde WhatsApp en formato .txt.
No es necesario instalar programas adicionales.

3. Ejecución

Descargar el repositorio.
Abrir el archivo index.html. En caso de hacerlo desde un editor de código, abrirlo mediante una extensión como Live Server.
Seleccionar un archivo de chat mediante el botón "Cargar archivo".
Visualizar las métricas y gráficos generados.

4. Limitaciones

No analiza contenido multimedia.
No procesa audios, imágenes, videos o documentos adjuntos.
